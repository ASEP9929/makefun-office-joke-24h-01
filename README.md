## The joke

> The office plant by my desk has been dead for six months, but HR keeps watering it because technically it's still on payroll.

## How it works

Run `node main.ts` — it writes the joke (125 characters, no trailing newline) to `/output/entry.txt`, after checking the line is within the 1–200 character gate and reading the file back to confirm it matches byte-for-byte.
